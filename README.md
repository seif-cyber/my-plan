# خطتي — PWA

جدول الجامعة + الإنتاجية كتطبيق يتثبّت على الآيفون، شغّال أوفلاين، فيه تتبّع إنجاز وتحليلات وتتبّع نوم.
مفيش سيرفر ولا مكتبات خارجية — كل حاجة ملفات ثابتة، فتشتغل على GitHub Pages مباشرة.

## الرفع على GitHub Pages
1. اعمل Repository جديد على GitHub (مثلاً `khotty`) — Public.
2. ارفع **محتويات** المجلد (مش المجلد نفسه): `index.html` و`app.js` و`styles.css` و`schedule.js` و`sw.js` و`manifest.webmanifest` و`icons/` و`.nojekyll`.
3. من **Settings ← Pages**: Source = *Deploy from a branch*، Branch = `main`، Folder = `/ (root)` ← Save.
4. بعد دقيقة هيطلعلك الرابط: `https://USERNAME.github.io/khotty/`

## التثبيت على الآيفون
1. افتح الرابط في **Safari** (لازم Safari، مش متصفح تاني).
2. زر المشاركة ⬆️ ← **إضافة إلى الشاشة الرئيسية** ← إضافة.
3. افتحه من الأيقونة — هيشتغل بملء الشاشة وبدون إنترنت.

## تعديل الجدول
كل الجدول في ملف واحد: `schedule.js`. غيّر الأوقات أو المحاضرات هناك وارفعه — التطبيق بيتحدّث تلقائياً عند الفتح (قد تحتاج تفتحه مرتين).
- `s` / `e` = البداية والنهاية بصيغة 24 ساعة، `c` = التصنيف (انظر `CATS` آخر الملف).
- التتبّع بيعتمد على (وقت البداية + التصنيف) لكل مهمة، فلو غيّرت وقت مهمة بتتحسب مهمة جديدة لليوم ده.

## البيانات والخصوصية
- التتبّع وسجل النوم محفوظين على جهازك (localStorage) — مش بيتبعتوا لأي مكان.
- مش متزامنة بين الأجهزة: استخدم **المزيد ← تصدير/استيراد** لعمل نسخة احتياطية أو نقل البيانات.
- مسح بيانات Safari أو حذف التطبيق بيمسح البيانات — خد نسخة احتياطية بشكل دوري.

## التنبيهات
iOS مبيدعمش تنبيهات مجدولة من PWA بدون سيرفر. الحل المدمج: **المزيد ← تنبيهات الآيفون** بيصدّر ملف تقويم (.ics) بتنبيه قبل كل محاضرة/مهمة، ويتكرر أسبوعياً لحد 31 يناير 2027.

## اشتراك التقويم (.ics)
زرار «اشتراك» في التطبيق بيربط تقويم الآيفون بملفات `khotty-lectures.ics` و`khotty-full.ics` اللي على الموقع.
الملفات دي **مش بتتحدّث لوحدها** — كل ما تغيّر `schedule.js` شغّل:

    node gen-ics.js

وارفع الملفين الجداد. التقويم بيسحب التحديث تلقائياً (كل كام ساعة).
